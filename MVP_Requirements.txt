MVP 需求规格说明（SWE.1）
项目：AutoMediaPlayer（Android 智能座舱本地音乐播放器）
版本：1.0
日期：2026-11-07
适用阶段：第 1 周 / 第二章 MVP——播放单曲

一、目标与范围
本周目标是形成最小可行闭环：授予音频读取权限 -> 扫描本地/USB 音乐 -> 列表展示 -> 点击播放单曲 -> 播放/暂停状态同步。
本版本不包含后台播放、播放队列、MediaSession、音频焦点、状态持久化与副驾屏协同，这些能力分别在后续周实现。

二、功能需求

REQ-MVP-001 权限管理（优先级：高）
描述：应用在清单中声明音频读取权限，并在运行时动态申请。
- Android 13（API 33）及以上：android.permission.READ_MEDIA_AUDIO。
- Android 12（API 32）及以下：android.permission.READ_EXTERNAL_STORAGE。
验收准则：
1. 首次启动且未授权时弹出系统权限对话框。
2. 授权后自动扫描音乐，列表可见。
3. 拒绝授权时应用不崩溃，界面给出明确提示，同时输出错误日志。
追溯：任务 T1-3；测试用例 CP1-02、CP1-03。

REQ-MVP-002 音乐扫描（优先级：高）
描述：使用 ContentResolver 查询 MediaStore 音频库，扫描内置存储与 U 盘等外部存储卷。
- 查询列：_ID、TITLE、ARTIST、ALBUM、DURATION。
- 分区存储下不依赖 DATA 绝对路径，播放地址由 ContentUris.withAppendedId() 构造 content:// Uri。
- 过滤条件：IS_MUSIC != 0 且 DURATION >= 45000 毫秒。
- 排序：按歌曲标题升序。
- 查询必须在 IO 线程执行，Cursor 使用 use{} 自动关闭。
验收准则：
1. 插入含 MP3 的 U 盘并启动应用后，歌曲出现在列表中。
2. 时长小于 45 秒的铃声/提示音不显示。
3. 列表按标题升序排列，空结果有提示。
追溯：任务 T1-4；测试用例 CP1-01、CP1-04。

REQ-MVP-003 歌曲列表（优先级：高）
描述：使用 RecyclerView + Adapter + ViewHolder 展示扫描结果，每项显示歌曲名、歌手、专辑与时长。
验收准则：
1. 列表项信息完整，长标题单行省略。
2. 点击任意列表项触发对应歌曲播放。
3. 列表为空时显示“未找到音乐文件”提示。
追溯：任务 T1-5；测试用例 CP1-04、CP1-05。

REQ-MVP-004 单曲播放（优先级：高）
描述：使用 MediaPlayer 播放点击的歌曲，并通过 content:// Uri 读取媒体文件。
- 每次切换歌曲先释放旧 MediaPlayer，再创建新实例。
- 使用 prepareAsync() 异步准备，在 OnPreparedListener 中启动播放。
- 使用 OnCompletionListener 与 OnErrorListener 复位状态并提示错误。
验收准则：
1. 点击列表项后开始播放，界面显示当前歌曲名与歌手。
2. 播放结束后播放按钮恢复为“播放”状态。
3. 文件损坏或格式不支持时应用不崩溃，并提示播放失败。
追溯：任务 T1-5；测试用例 CP1-05、CP1-07。

REQ-MVP-005 播放控制与状态显示（优先级：高）
描述：提供播放/暂停切换与上一首/下一首按钮；播放按钮图标随状态切换。
验收准则：
1. 播放中点击按钮暂停，再次点击继续播放。
2. 播放中显示暂停图标，暂停或停止时显示播放图标。
3. 没有当前歌曲时点击播放按钮，自动播放列表第一首；列表为空时给出提示。
追溯：任务 T1-5；测试用例 CP1-06。

REQ-MVP-006 界面布局（优先级：高）
描述：主界面左侧 70% 显示当前播放信息与大尺寸控制按钮，右侧 30% 显示歌曲列表。
验收准则：
1. 1080P/车机横屏下左右分栏比例正确，无控件重叠。
2. 歌曲标题、歌手、列表项与按钮清晰可读，按钮点击区域不小于 48dp。
追溯：任务 T1-2、T1-5；测试用例 CP1-08。

三、非功能需求
NFR-001 性能：媒体库查询在 Dispatchers.IO 执行，不阻塞主线程；扫描期间界面可响应。
NFR-002 稳定性：权限拒绝、空列表、损坏文件等异常路径不崩溃。
NFR-003 资源管理：MediaPlayer 在 Activity 销毁或切换歌曲时 release()，Cursor 查询后自动关闭。
NFR-004 可维护性：按 model / util / adapter / ui 分层，包结构清晰，关键逻辑有中文注释。
NFR-005 兼容性：minSdk 31；兼容 Android 13+ 与 Android 12 及以下的存储权限模型。

四、明确不包含（后续周迭代）
- 后台播放与前台服务（第 2 周）。
- 播放队列与顺序/循环/随机模式（第 2 周）。
- MediaSession / MediaBrowserService 系统集成（第 3 周）。
- 车机 UI 深度优化与状态持久化（第 4 周）。
- 音频焦点、USB 热插拔、副驾屏与硬按键（第 5 周）。

五、验收环境与演示路径
1. 准备 FAT32 U 盘，根目录或子目录放置若干时长不少于 45 秒的 MP3。
2. 将 U 盘插入车机/台架，安装并启动 app-debug.apk。
3. 首次启动授予音频读取权限。
4. 确认右侧列表出现歌曲；点击一首歌曲，左侧显示标题/歌手并开始播放。
5. 点击播放/暂停按钮，确认图标与播放状态同步。
